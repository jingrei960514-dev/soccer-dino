# assets：圖片和音效

把圖檔或音效檔放進這個資料夾，檔名照下面的表格取，遊戲就會自動使用。找不到的檔案會自動改用幾何圖形或內建的嗶聲，所以這個資料夾是空的也能玩。

改了這裡的檔案之後，重新執行 notebook 的最後一格就會生效，不用重新啟動 kernel。

## 圖片

| 檔名 | 角色 | 會縮放成（寬 x 高） | 對齊方式 |
| --- | --- | --- | --- |
| `player.png` | 球員 | 60 x 80 | 底部中間對準球員的腳 |
| `cone.png` | 三角錐 | 36 x 44 | 底部貼地 |
| `defender.png` | 鏟球的防守球員，腳朝左 | 72 x 34 | 底部貼地 |
| `ball.png` | 地上的足球 | 24 x 24 | 底部貼地 |
| `shoe.png` | 飛過來的球鞋 | 30 x 30 | 飄在站著的球員頭頂上方；用圖片時不會翻轉 |
| `shot.png` | 射出去的球 | 18 x 18 | 底部貼地 |
| `goal.png` | 球門，球門柱在左邊 | 80 x 150 | 底部貼地，左邊緣就是過關線 |
| `background.png` | 整個背景 | 960 x 480 | 填滿畫面，不會捲動 |

- 用有透明背景的 **PNG**，角色周圍才不會有一塊白底。
- 不管原圖多大都會縮放成上面的大小，所以寬高比例要接近，不然會被拉扁。障礙物的碰撞判定就是這個大小，所以圖的主體最好畫滿整張圖。球員例外：碰撞框只有中間 40 像素寬，兩側留給手臂。
- 用 `player.png` 時，學生選的球衣顏色和背號不會顯示，因為球員的樣子都畫在圖裡了。名字仍然會顯示在頭上。
- 背景圖的地面要在從上往下數第 400 像素的位置，和球員的腳對齊。背景不會捲動，因為整片背景一起滑動很容易頭暈。
- 大小、檔名都可以在 `config.py` 的 `image_files`、`image_sizes` 修改。

## 音效

| 檔名 | 什麼時候播放 |
| --- | --- |
| `jump.wav` | 跳起來 |
| `hit.wav` | 撞到障礙物 |
| `ball.wav` | 撿到地上的足球 |
| `shoot.wav` | 射門 |
| `kick.wav` | 射門踢飛防守球員 |
| `win.wav` | 抵達球門 |
| `lose.wav` | 遊戲結束 |

- 想用 .ogg 檔的話，在 `config.py` 的 `sound_files` 把檔名改成 .ogg。
- 音量在 `config.py` 的 `sound_volume` 調整；想全部關掉，把 `sound_enabled` 改成 `False`。
- 電腦沒有喇叭或音效卡時會自動靜音，遊戲照常玩。

## 版權

只能放自己畫的、自己錄的，或是授權允許自由使用的素材（例如標示 CC0 的素材）。不要放真實球員的照片或球隊的標誌。
